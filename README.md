💎 Handmade Jewelry

Handmade Jewelry — командный учебный проект, разработанный в рамках курса Fullstack Developer от GoIT.

Цель проекта — создать современный адаптивный веб-сайт украшений ручной работы по макету из Figma.

Проект разрабатывается командой из 9 участников. Каждый участник отвечает за свою часть сайта и работает через отдельную Git-ветку с последующим созданием Pull Request и объединением изменений в основную ветку проекта.

🤝 Командная работа

Для организации разработки команда использует GitHub, Trello и Figma.

Каждый участник работает над своей секцией сайта в отдельной ветке. После завершения работы создаётся Pull Request, код проходит проверку и затем объединяется с основной веткой main.

Team Lead отвечает за интеграцию проекта и объединение изменений участников.

Scrum Master помогает организовать командную работу, контролировать выполнение задач и следить за актуальностью задач в Trello.

Проект позволяет получить практический опыт командной разработки, работы с Git/GitHub, Pull Requests, адаптивной верстки и совместной интеграции отдельных частей сайта в единый проект.
